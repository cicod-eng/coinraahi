Blockchain Basics Without the Jargon

Last updated: 6 September 2026

You do not need to become a developer to understand how a blockchain transaction works. Think of a blockchain as a shared record that many computers agree on.

Transaction

A transaction is an instruction. Examples include sending BTC, transferring USDT or interacting with a smart contract.

Block

Networks group transactions into blocks or equivalent data structures. Blocks help create an ordered transaction history.

Validator or miner

Different networks use different consensus mechanisms. Bitcoin uses mining. Ethereum uses validators under proof of stake. The purpose is similar: agree on valid network state.

Confirmation

A transaction can be broadcast before it becomes sufficiently confirmed. Exchanges often wait for multiple confirmations before crediting deposits.

Address

A blockchain address identifies a destination. It is not the same thing as a person’s verified identity.

Network fee

Fees compensate or incentivise network processing. Different blockchains calculate them differently.

Blockchain explorer

A block explorer lets you independently inspect transaction status, address, amount, block and confirmations. This is why a TXID can be more useful than an app screenshot.

Smart contract

A smart contract is code deployed to a blockchain. It can manage tokens, swaps, lending and tokenised assets. But code can contain risks.

Different networks are not interchangeable

Ethereum, TRON, BNB Smart Chain and Bitcoin are separate systems. Even when address formats look similar, the network matters.

Frequently asked questions

Is blockchain the same as Bitcoin?

No. Bitcoin uses blockchain technology, but other networks also use blockchain-based systems.

Can blockchain transactions be deleted?

Public blockchain history is generally designed to be persistent once finalised.

Why do exchanges wait for confirmations?

To reduce the risk of crediting a transaction before the network considers it sufficiently settled.

What is a TXID?

The transaction identifier used to find an on-chain transaction.
